# Frontend

Планируемый стек: React, TypeScript и Vite со статической SPA-сборкой для PyWebView.

Главный интерфейс — канонические матричные формы. Даты остаются горизонтальными колонками; объекты и показатели — вертикальными группами в утверждённом порядке. Карточки, Kanban и календарь не могут заменять основной матричный ввод.

Реализован только транспортно-независимый TypeScript-контракт матричной ячейки и frontend-
сущность `report-cell`. React/Vite-приложение и формы ещё не реализованы: сначала требуются
утверждённые эталоны и карта ячеек этапа 0.
