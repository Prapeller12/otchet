# Frontend

Стек: React, TypeScript и Vite со статической SPA-сборкой для PyWebView.

Главный интерфейс — канонические матричные формы. Даты остаются горизонтальными колонками; объекты и показатели — вертикальными группами в утверждённом порядке. Карточки, Kanban и календарь не могут заменять основной матричный ввод.

Реализованы три переключаемые матрицы, фиксированные заголовки, клавиатурный ввод,
различие пустого значения и нуля, состояния сохранения и адаптеры для PyWebView и браузерной
демонстрации. Режим подключения всегда виден в заголовке: только PyWebView-режим сохраняет
данные в SQLite.

До утверждения эталонов интерфейс показывает статус `WORKING_REFERENCE`, использует
обезличенные строки, блокирует расчётные ячейки и Excel import/export.
