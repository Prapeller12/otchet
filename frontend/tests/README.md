# Frontend tests

`contracts/report-cell-contract.test.mjs` автономно проверяет JSON Schema, примеры и
согласованность основных TypeScript-дискриминаторов без npm-зависимостей.

Строгая проверка всех текущих frontend `.ts` выполняется закреплённой версией TypeScript:

```text
npm ci --ignore-scripts --no-audit --no-fund
npm run typecheck
node frontend/tests/contracts/report-cell-contract.test.mjs
```

После утверждения форм здесь должны появиться тесты структуры матриц, клавиатурной навигации,
вставки диапазона, блокировки расчётных ячеек и сохранения состояния.

## Dev.34: единый черновик и заготовки

`unified-draft-dev34.test.tsx` проверяет совместный пакет шапки, выпуска/плана и первичных
ячеек, переходы с черновиком, сохранение после конфликта, откат пользовательского
черновика, неизвестный результат записи, поиск без скрытия строк и отличия пустого
значения от нуля. Повтор после неизвестного результата отправляет тот же пакет и
тот же `idempotency_key`; новая запись и отбрасывание до установления результата
не допускаются. Отдельно проверяется успешная запись при неудавшемся обновлении экрана.
После импорта и удаления производителя проверяются новая ревизия следующей записи
и восстановление последних сохранённых строк при отбрасывании черновика.

`authorized-gateway.test.ts` дополнен проверками свежего кода для целого пакета и
для чтения результата, независимых состояний подписи/резервной копии, неполных
ответов и администраторской авторизации создания заготовок.

`blank-profile-workspace-dev34.test.tsx` использует синтетические размеры и проверяет
защиту диалога создания, открытие КГЭ как головной площадки с сентября 2027 года,
недоступность более раннего периода и выбор дочерней формы для остальных заготовок.
Реальные размеры проверяются backend и тестами профилей, а не синтетическим UI fixture.
Проверяются удержание блокировки до открытия созданных форм, цикл Tab в диалоге
и возврат фокуса на кнопку открытия после Escape.

Все эти проверки выполняются Vitest/Testing Library в jsdom. Они не заменяют
проверку окна, PDF и печати на целевых Windows 10/11.
