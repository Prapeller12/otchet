# Backend

Здесь будет находиться Python-backend со слоями:

- `api/` — HTTP/IPC-адаптеры без бизнес-формул;
- `application/` — сценарии использования и транзакционные границы;
- `domain/` — доменные сущности, точные значения и расчёты;
- `repositories/` — абстракции доступа к данным;
- `infrastructure/` — реализации SQLite/PostgreSQL и внешние адаптеры;
- `migrations/` — последовательные неизменяемые миграции;
- `tests/` — unit, интеграционные и контрактные тесты.

Прикладной код не добавлен: этап 1 заблокирован незавершёнными контрактами этапа 0.
