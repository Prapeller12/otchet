# Backend

Python-backend разделён по слоям:

- `api/` — HTTP/IPC-адаптеры без бизнес-формул;
- `application/` — сценарии использования и транзакционные границы;
- `domain/` — доменные сущности, точные значения и расчёты;
- `repositories/` — абстракции доступа к данным;
- `infrastructure/` — реализации SQLite/PostgreSQL и внешние адаптеры;
- `migrations/` — последовательные неизменяемые миграции;
- `tests/` — unit, интеграционные и контрактные тесты.

Сейчас реализованы чистые расчёты в `domain/`, SQLite-мигратор, начальная миграция
подтверждённого ядра и отдельная миграция неизменяемости утверждённого BOM. Для результата
процента с бесконечной десятичной записью требуется отдельное правило округления; до его
утверждения домен возвращает явную ошибку вместо неявной потери точности. API,
application-сервисы и репозитории будут добавлены после утверждения оставшихся контрактов
этапа 0.
