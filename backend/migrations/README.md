# Миграции

Миграции добавляются последовательно. Применённая миграция никогда не редактируется; исправление оформляется новой миграцией.

`0001_initial_schema.sql` создаёт подтверждённое ядро SQLite: организации, изделия,
компоненты, версии и строки BOM, складские и производственные операции. Количества хранятся
как проверенные десятичные строки, внешние ключи включены, пересекающиеся утверждённые версии
BOM запрещены, проведённые операции неизменяемы и исправляются отдельным сторно.

Применение:

```bash
python -m backend.infrastructure.database.migrator data/reporting.sqlite3
```

Мигратор применяет файлы по порядку, записывает SHA-256 и отклоняет изменение уже применённой
миграции. Полные таблицы пользователей, ролей, периодов, планов, договоров, импорта и аудита
будут добавлены отдельными миграциями только после фиксации соответствующих контрактов.
