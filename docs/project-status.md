# Состояние проекта

Дата фиксации: 30.08.2026
Текущий этап: **0 — фиксация контрактов**

## Подтверждено

- назначение и неизменяемые принципы из `AGENTS.md`;
- базовый стек: Python 3.12, PyWebView, React + TypeScript + Vite, SQLite для локального MVP;
- переносимая `onedir`-поставка в ZIP без установки и прав администратора;
- три канонических типа матричных отчётных форм;
- различие пустого значения и подтверждённого нуля;
- базовые формулы и контрольное значение `floor(71 / 3) = 23`;
- технические файловые логи, телеметрия и внешние сетевые обращения в локальном режиме по умолчанию выключены;
- бизнес-аудит внутри БД обязателен.

## Подготовлено

- базовая структура backend, frontend, config, resources, scripts и docs;
- защита Git от попадания runtime, БД, пользовательских данных и секретов;
- шаблон ADR и реестр эталонных форм;
- конфигурация только для требований, уже подтверждённых в `AGENTS.md`;
- локальная и CI-проверка обязательной структуры.

## Блокирует этап 1

Следующие сведения отсутствуют в репозитории и не могут быть восстановлены догадкой:

1. Утверждённая DEV-документация — главный источник требований по `AGENTS.md`.
2. Эталонные Excel-файлы и/или изображения всех трёх отчётных форм.
3. Перечень организаций и схема подчинённости.
4. Коды изделий, модификаций, ДСЕ и ПКИ.
5. Карта вводимых, расчётных и импортируемых ячеек каждой формы.
6. Источник и дата каждого вида факта.
7. Матрица прав ролей и правила закрытия/повторного открытия периода.
8. Состав и срок хранения бизнес-аудита.

До получения и утверждения этих материалов нельзя корректно проектировать рабочую схему БД, импорт и frontend-матрицы.

## Следующее решение владельца

Загрузить в `resources/templates/` утверждённые обезличенные Excel-шаблоны и заполнить для каждого шаблона карточку в `docs/ui-contracts/reference-form-register.md`.
