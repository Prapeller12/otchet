# Состояние проекта

Дата фиксации: 01.09.2026
Текущий этап: **технический сквозной preview; производственная приёмка не начата**

## Подтверждено

- назначение и неизменяемые принципы из `AGENTS.md`;
- базовый стек: Python 3.12, PyWebView, React + TypeScript + Vite, SQLite для локального MVP;
- переносимая `onedir`-поставка в ZIP без установки и прав администратора;
- три канонических типа матричных отчётных форм;
- различие пустого значения и подтверждённого нуля;
- базовые формулы и контрольное значение `floor(71 / 3) = 23`;
- технические файловые логи, телеметрия и внешние сетевые обращения в локальном режиме по умолчанию выключены;
- бизнес-аудит внутри БД обязателен;
- DEV-документация v0.5 утверждена владельцем программы 31.08.2026 для текущего этапа
  разработки;
- приложенные формы исследованы как рабочие источники, но ещё не утверждены как эталоны.

## Подготовлено

- базовая структура backend, frontend, config, resources, scripts и docs;
- защита Git от попадания runtime, БД, пользовательских данных и секретов;
- шаблон ADR и реестр эталонных форм;
- конфигурация только для требований, уже подтверждённых в `AGENTS.md`;
- локальная и CI-проверка обязательной структуры;
- обезличенный реестр и отдельные карточки трёх форм без публикации частных метаданных;
- доменные расчёты остатка, потребности, готовности, дефицита, договорного отклонения и
  выполнения плана на `Decimal`;
- начальная SQLite-миграция организаций, изделий, компонентов, версий BOM и неизменяемых
  операций со сторно;
- dependency-free мигратор с проверкой контрольных сумм и транзакционным применением;
- JSON Schema и TypeScript-контракт матричной ячейки с различием пустого значения и нуля;
- unit, integration и contract-тесты для реализованного фундамента.
- versioned `WORKING_REFERENCE`-описания всех трёх матриц с JSON Schema;
- application-service и SQLite-репозиторий неизменяемых ревизий матричных фактов;
- PyWebView bridge и React/Vite-интерфейс с реальным сохранением в SQLite;
- браузерный demo-адаптер, явно помеченный как режим без сохранения на диск;
- launcher, single-instance lock, backup-before-migration и fail-closed release verifier;
- Windows build/package scripts для `onedir` ZIP со встроенными Python и Fixed WebView2.

## Не завершено и блокирует производственный выпуск

Следующие решения нельзя восстановить догадкой:

1. Утверждение конкретных версий форм по контрольным суммам, хранящимся вне публичного
   репозитория.
2. Перечень организаций и схема подчинённости.
3. Коды изделий, модификаций, ДСЕ и ПКИ.
4. Карта вводимых, расчётных и импортируемых ячеек каждой формы.
5. Источник и дата каждого вида факта.
6. Матрица прав ролей и правила закрытия/повторного открытия периода.
7. Состав и срок хранения бизнес-аудита.
8. Полный контракт Excel-импорта и допустимое изменение оформления книг.
9. Правило точности и округления процентов, если результат имеет бесконечную десятичную
   запись.

До этих решений нельзя корректно включить производственные справочники, расчётные привязки,
права, закрытие периодов и Excel import/export. Технический preview намеренно работает на
синтетических идентификаторах и не выдаётся за принятую производственную модель.

Отдельно открыт `ADR-0001`: WebView2 Fixed Runtime 120+ на Windows 10 требует настройки ACL,
тогда как исходные требования запрещают автоматическое изменение прав. До письменного
решения и проверки на чистых Windows 10/11 portable ZIP не имеет статуса принятого релиза.

## Следующее решение владельца

Утвердить или отклонить каждую версию формы из
`docs/ui-contracts/reference-form-register.md`; после подтверждения предоставить
обезличенные копии для `resources/templates/` и карту ячеек.
