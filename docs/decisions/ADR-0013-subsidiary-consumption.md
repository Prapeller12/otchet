# ADR-0013: Дочерние общества — расход по поставщикам
Статус: ACCEPTED
Дата: 2026-09-11

Решение владельца в диалоге: деталь объединяет производителей. Недельные значения — расход, I — месячные поступления. План детали = месячный план составной части C6 × входимость. Остаток = начальный остаток + месячные поступления − расход до выбранной недели. Отклонение = начальный остаток + поступления − потребность; расход повторно не вычитается.

Настройки детали хранят устойчивые идентификаторы поставщиков. Удаление архивирует поставщика, не уничтожая историю. Старые значения «Поставка» не превращаются в расход и доступны отдельной историей. Пустые исходные значения не подменяются нулём. Месячный начальный остаток вводится явно; автоматический перенос не утверждён.

UI: поля детали общие, поставщики отдельными строками, календарные недели по ранее утверждённому правилу. Белые вводимые и серые расчётные ячейки, красный дефицит. PDF использует тот же месячный снимок и недельные колонки. Backend владеет всеми расчётами.

Существующие JSON-настройки расширяются без изменения применённых миграций. Новые факты используют отдельные коды, старые сохраняются. Откат к предыдущей версии не удаляет новые факты, но не отображает их.

Проверки: несколько поставщиков, пустое/ноль, пять недель, независимость месячного отклонения от расхода, архивирование, сохранение/перезапуск, экспорт/импорт, недельный PDF.
