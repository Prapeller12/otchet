# ADR-0024: заготовки пяти площадок с сентября 2027

Статус: ACCEPTED в пределах явного поручения пользователя от 2026-10-11.

## Основание и границы

Пользователь поручил изменить программу и создать заготовки по пяти приложенным
книгам: КГЭ — головная площадка; Молот, Кулакова, СРЗ и Равенство — дочерние.
Начальный период — сентябрь 2027. Названия и наименования пользователь заполнит сам.
Это решение не утверждает новые нормы, категории, BOM или числовые данные.

## Решение

1. Новый административный сценарий показывает размеры и создаёт отдельный набор
   пяти организаций одной транзакцией. Прежние организации и записи сохраняются.
   Повторный вызов открывает существующий набор без перезаписи. Частичный набор
   или занятые идентификаторы требуют исправления, а не дописываются вслепую.
2. Размеры позиций: 8 / 154 / 69 / 82 / 62. Позицию определяет непустой якорь
   наименования в исходном столбце D, включая позиции без обозначения C.
   Число различных заполненных исходных производителей: 8 / 33 / 7 / 17 / 17.
   Точное совпадение после обрезки внешних пробелов определяет один технический слот.
3. В программе обязательные имена содержат явные технические подписи «… · заполните».
   Оригинальные деловые наименования, изображения и количества не входят в ресурс.
   XLSX содержит пустые редактируемые имена и справочник повторяющихся производителей.
4. Сохраняются позиции без производителя и дополнительные пустые физические строки.
   `empty_supplier_slots` хранит число незаполненных строк, а не вымышленных поставщиков.
   Они видны в матрице; показатели виртуальных производителей недоступны для записи.
   Добавление настоящего производителя занимает один пустой слот.
5. Нормы, договорные количества, факты и планы отсутствуют, категория UNSPECIFIED.
   Пустота не превращается в ноль. Связи между изделиями и комплектующими не выведены
   из похожих наименований и заполняются отдельно.
6. `start_period=2027-09-01` и первоначальный выбор 2027/09 относятся только к этому
   набору. Запись и импорт до начала периода запрещены; прежние отчёты не ограничены.
7. При исходной ошибке объединений номера XLSX согласуются с блоками D. В «Молоте»
   исправление раскрывает девять ранее скрытых номеров; физические строки сохраняются.

## Проверка

Тесты проверяют размеры, иерархию parent_id, пустые количества, видимость всех позиций,
откат всего набора при ошибке третьей организации и сохранение ручных изменений при
повторном вызове. Независимая проверка сравнивает размеры с пятью исходными книгами.
Проверка реальных рабочих мест Windows 10/11 и пользователей остаётся выпускным условием.
