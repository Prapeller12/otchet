# ADR-0001: WebView2 Fixed Runtime 120+ и ACL в Windows 10

Статус: **PROPOSED**
Дата: 01.09.2026

## Причина

Утверждённая DEV-документация требует одновременно:

- переносимую ZIP-сборку без установки и прав администратора;
- WebView2 Fixed Runtime внутри каталога программы;
- отсутствие автоматического изменения ACL через `icacls`.

Microsoft указывает, что на Windows 10 для unpackaged Win32-приложений с Fixed Version
Runtime начиная с версии 120 необходимо предоставить каталогам runtime права чтения и
выполнения для `ALL APPLICATION PACKAGES` и `ALL RESTRICTED APPLICATION PACKAGES`.
Официальный источник: [Distribute your app and the WebView2 Runtime](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution#details-about-the-fixed-version-runtime-distribution-mode).

Это требование Microsoft не относится к Windows 11, но выпуск должен поддерживать обе
целевые ОС. Обычный ZIP не является доказательством того, что после распаковки необходимые
NTFS ACL присутствуют в выбранном пользователем каталоге.

## Текущее поведение

Программа не запускает `icacls`, не меняет ACL и не запрашивает повышение прав. Сценарий
сборки требует реальный Fixed Runtime, но Windows 10 не считается принятым без отдельного
испытания прав каталога.

## Предлагаемое изменение

Решение владельца пока не принято. Допустимые варианты для проверки:

1. Разрешить launcher точечно добавлять только две документированные Microsoft записи RX к
   `runtime/webview2`, если текущий пользователь является владельцем каталога. Операция
   должна быть явной, проверяемой и не затрагивать остальные каталоги.
2. Перейти на Evergreen Runtime. Это уменьшает размер поставки и снимает Fixed Runtime ACL,
   но нарушает требование автономной поставки runtime и требует наличия/установки WebView2.
3. Выбрать другую desktop-оболочку с отдельным ADR и повторным сравнением автономности,
   размера и рисков.
4. Ограничить поддерживаемую ОС Windows 11. Это меняет утверждённую целевую платформу.

Использование устаревшего Fixed Runtime ниже 120 не предлагается из-за отсутствия актуальных
исправлений безопасности.

## Влияние на UI

До решения возможна понятная блокирующая ошибка запуска в Windows 10, если WebView2 не может
инициализировать AppContainer из-за прав каталога. Основные матричные формы не меняются.

## Влияние на данные и миграции

Нет. Проверка WebView2 выполняется до пользовательского ввода. Миграции и база не должны
использоваться для хранения решения об ACL.

## Влияние на API

Нет.

## Влияние на portable-сборку

Windows 11 можно проверять с Fixed Runtime без этого дополнительного шага. Windows 10 нельзя
объявлять прошедшей приёмку только по факту успешной сборки ZIP; требуется чистая VM и
проверка запуска из каталога с пробелами и кириллицей под обычным пользователем.

## Риски

- без нужных ACL WebView2 может не запуститься или часть функций может работать неверно;
- скрытое изменение ACL нарушит утверждённое требование и ожидания пользователя;
- Evergreen создаст зависимость от установленного и обновляемого системного runtime;
- устаревший Fixed Runtime создаст неприемлемый риск безопасности.

## План отката

Пока ADR имеет статус `PROPOSED`, код изменения ACL не добавляется. Любой эксперимент
проводится только на копии сборки в тестовой Windows VM.

## Необходимые тесты

- Windows 10 x64 и Windows 11 x64, обычный пользователь, без повышения прав;
- локальный путь с пробелами и кириллицей;
- проверка фактически используемой версии Fixed Runtime;
- запуск после обычной распаковки ZIP;
- отсутствие изменений ACL вне `runtime/webview2` для варианта 1;
- повторный запуск и удаление тестовой копии без остаточных блокировок приложения.

## Решение владельца

**OPEN.** Требуется отдельное письменное решение до подтверждения Windows 10 portable.
