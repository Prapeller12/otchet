# ADR-0002: канонический Excel round-trip

- Статус: `ACCEPTED`
- Дата: 02.09.2026
- Автор: команда разработки

## Причина

Владелец потребовал рабочие кнопки загрузки и выгрузки Excel для ручного тестирования.
Исторические книги отличаются структурой и не имеют утверждённой полной карты координат.

## Решение

Программа экспортирует каноническую `.xlsx`-книгу из текущей матрицы. Вводимые ячейки
разблокированы и связаны с бизнес-координатами в скрытом системном листе. Импорт принимает
только такую книгу для той же формы и организации.

Перед записью исходный файл копируется в `imports/inbox`, вычисляется SHA-256, значения
классифицируются как `NEW / CHANGED / SAME / ERROR` и показываются пользователю. Проведение
выполняется только после подтверждения и создания резервной копии SQLite. Повторный импорт
того же проведённого файла не создаёт новых ревизий.

## Влияние

- UI получает работающие native file dialogs и окно предпросмотра.
- Миграция `0005` хранит пакеты, строки и ошибки импорта.
- Portable-сборка включает `openpyxl`.
- Прямой импорт произвольных исторических книг остаётся отдельным адаптером, чтобы не
  угадывать их смысл по номерам ячеек.

## Риски и откат

Пользователь может повредить скрытую карту или вставить формулу в поле ввода; такой файл
отклоняется до записи. Откат кода не удаляет проведённые ревизии; база восстанавливается из
созданной перед импортом резервной копии.

## Необходимые тесты

- export → изменение жёлтой ячейки → preview → confirm → reload для трёх форм;
- отклонение посторонней книги и формулы в поле ввода;
- защита от повторного импорта по SHA-256;
- ручной выбор файлов и сохранение на Windows portable.

## Решение владельца

Владелец 02.09.2026 потребовал полный рабочий функционал Excel без неработающих кнопок.
