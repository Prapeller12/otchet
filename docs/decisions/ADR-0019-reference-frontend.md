# ADR-0019: Экранный интерфейс по Frontend Reference Kit

Статус: ACCEPTED — прямое указание владельца от 20.09.2026: привести frontend
к документации Frontend_Reference_Kit_v1(2).zip; шрифты печатных отчётов не менять;
проверить наличие иконок на кнопках только там, где они полезны.

## Решение и границы

Применить визуальную систему комплекта к существующему React/TypeScript frontend:
локальный Golos Text, светлая поверхность, красный основной акцент, размеры и
состояния кнопок/полей, оформление таблиц, вкладок и диалогов. Образец не заменяет
три матрицы отчётности или их бизнес-данные. Сохраняются порядок строк/дат,
числовые поля, накопительный итог, закрепление вкладок, роли, шифрование и подписи,
обмен Excel и PDF, переносимый запуск PyWebView/Fixed WebView2.

Тема, размеры и SVG-геометрия размещаются отдельно от предметной логики. Локальные
шрифты поставляются с лицензией OFL; сетевых ресурсов не добавлять. Применять
экранную тему отдельно от печати. Backend PDF, печатные шрифты, их размеры и
шаблоны остаются неизменны. Не импортировать print.css образца.

Иконки сопровождают текст узнаваемого действия: сохранить, печать, импорт/экспорт,
настройка, изменение, добавление, удаление, помощь, назад, закрытие. «Ещё» получает
стрелку раскрытия с корректным состоянием. Кнопки только с иконкой имеют доступное
имя; декоративные SVG скрыты от screen reader. Ячейки чисел, выбор месяца и
простые текстовые варианты не получают украшений без смысла.

## Реализация и данные

Новых миграций, зависимостей исполнения, транспортных команд и бизнес-формул нет.
Заполняются профиль, карта переноса и обоснованные отклонения по схемам архива.
Старые экранные стили адаптируются с сохранением прежнего печатного каскада.
Комплект-эталон и исходные рабочие данные не изменяются.

## Проверки

Проверить доступные имена и геометрию иконок, раскрытие меню, состояния кнопок,
клавиатурный ввод, сохранение с кодом, подпись/PDF, импорт, накопительный итог и
закрепление навигации. Сравнить контрольные расчёты и неизменность печатных
исходников. Проверить локальную загрузку Golos в настоящем Windows-окне из ZIP,
снимки трёх отчётов и диалогов, читаемость при ограниченной высоте окна.
Не заявлять проверку всех масштабов ОС без фактического прогона.

## Откат

Предыдущая dev.28 совместима с базой: изменения относятся к экранному представлению.
Вернуться к прежней распакованной программе с полной резервной копией данных;
миграции и история не меняются.
