# ADR-0021: отключаемые подсказки полей

Статус: ACCEPTED. Дата: 26.09.2026.
Основание: прямое указание владельца включать и отключать подсказки при наведении.

Единый переключатель «Подсказки при наведении» рядом с «Как заполнить» управляет
всплывающими пояснениями всех отчётов. По умолчанию включён. Выключение закрывает
открытое пояснение и предотвращает его появление при наведении/фокусе. Основная
клавиатурная навигация ячеек, ошибки ввода и обычные подписи действий сохраняются.

Состояние хранится отдельно от производственных данных в config/ui-preferences.json.
Приватный режим WebView2 сохраняется: localStorage не используется как постоянное
хранилище. Bridge принимает только поле field_hints_enabled типа boolean. Файл
записывается атомарно; ошибки записи видны пользователю, состояние откатывается.
Изменение личного оформления не требует подписи производственного отчёта и кода.
Это узкое исключение для настройки интерфейса; политика доступа бизнес-команд,
криптографические ключи и миграции БД не меняются. Печатные формы не изменяются.

Настройка относится к данной папке программы и всем её пользователям; при обновлении
в новую папку её можно перенести отдельно. Она исключается из Git и чистой поставки.
Отсутствующий/повреждённый файл даёт безопасное значение по умолчанию — включено.
Проверки: on/off во всех формах, открытая подсказка, фокус, черновик, ошибка записи,
чистая поставка и повторный EXE с выключенными подсказками, затем включение обратно.
Откат: удалить настройку при закрытой программе или включить переключатель.
