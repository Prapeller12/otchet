# Протокол изменений рабочего интерфейса от 02.09.2026

Статус: реализуемое указание владельца для `WORKING_REFERENCE`.

## Основание

Ручная оценка Windows preview показала, что технические обозначения ячеек и жёстко заданные
поля мешают работе с матрицей. Владелец потребовал изменить представление сумм, убрать
явную легенду, разрешить настройку изготовителей/позиций, поддержать множество дочерних
обществ и перенести состояние SQLite в нижнюю строку.

## Изменения относительно предыдущего preview

| Область | Было | Стало |
|---|---|---|
| Ежедневный отчёт | Значок `Σ` повторялся внутри календарных ячеек | Сумма строки и признак расчёта показываются в колонке `Показатель` |
| Легенда | Постоянная строка с названиями состояний | Убрана; состояние доступно через оформление, подсказку и нижнюю строку |
| Изготовитель/позиция | Значения жёстко задавались рабочим описателем | Редактируются в отдельном окне настройки рабочего поля |
| Строки | Нельзя было добавлять и убирать | Повторяемые позиции добавляются, переставляются и архивируются |
| Организации | Один технический пример | Головная площадка и произвольное число дочерних обществ с переключателем |
| SQLite | Статус находился в шапке | Статус находится в нижней строке, рядом с текущей ячейкой и контекстом отчёта |

## Сохранённые ограничения

- календарные даты остаются горизонтальной осью;
- обязательный порядок показателей внутри добавленной позиции не меняется;
- расчётные ячейки остаются недоступными для ручного ввода;
- пустое значение и подтверждённый ноль не объединяются;
- удаление позиции или дочернего общества реализуется архивированием, без удаления фактов;
- перечень реальных организаций и бизнес-коды остаются пользовательской настройкой, а не
  встроенным справочником.
