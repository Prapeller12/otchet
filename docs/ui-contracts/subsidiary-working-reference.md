# Дочерние общества: рабочая форма dev.13

Основание: решения владельца 11.09.2026, ADR-0013. Эта спецификация заменяет прежнюю универсальную матрицу поставок для вкладки SUBSIDIARY.

Деталь имеет номер (включая иерархический номер), обозначение, наименование, категорию, входимость и изображение. Одна деталь содержит несколько производителей с устойчивыми идентификаторами и отдельными договорными объёмами. Эти поля редактируются в настройках. В основной матрице есть команда «Убрать производителя»; архивирование сохраняет историю. Архивные строки с данными выбранного года остаются видны и участвуют в расчёте.

В месячном блоке: общий начальный остаток детали, поступления каждого производителя, общий складской остаток, общий дефицит/профицит и недельный расход по каждому производителю. Номер, обозначение, название и входимость объединены по строкам производителей. Начальный остаток вводится только в первой строке детали. Начальные остатки месяцев независимы: автоматический перенос не согласован.

План готовой составной части (C6) задаётся отдельно для каждого месяца и организации. Потребность каждой детали = C6 × входимость. Договорной объём в этот расчёт не входит.

- Остаток на выбранную неделю = начальный остаток + поступления месяца − внесённый расход до конца выбранной недели.
- Дефицит/профицит = начальный остаток + поступления месяца − C6 × входимость.
- Пустое значение начального остатка или поступлений действующего производителя блокирует расчёт, подтверждённый ноль участвует в расчёте. Расход суммируется по внесённым значениям, пустые ячейки остаются видимыми как непредставленные данные.
- Недели понедельник–воскресенье обрезаются границами месяца. Граничные фрагменты 1–2 дня объединяются с соседней неделей этого месяца, 3+ дня самостоятельны.

Поставщики архивируются, записи количеств не удаляются. Прежние показатели, названные «Поставка», не переименовываются в расход: доступны отдельной таблицей истории со стабильными координатами.

Оформление: белые вводимые ячейки, светло-серые расчётные и заголовки, тонкие границы. Отрицательный дефицит выделяется бледно-красным и знаком минуса.

PDF: отдельная форма A4 landscape, весь месяц по ширине, недельные колонки, перенос строк вниз, повторение заголовков, дата выбранного остатка и отметка проверки. Подтверждение относится к снимку с выбранной неделей остатка; смена недели меняет снимок.

Excel: действующая матрица с устойчивой системной картой для обратного импорта; месячные планы отдельным защищённым листом. Вычисленные значения — снимок backend, пересчёт после импорта в программу. Импорт исходного образца использует существующее явное сопоставление ячеек. Автоматического восстановления всей структуры изделия из старого Excel нет.
