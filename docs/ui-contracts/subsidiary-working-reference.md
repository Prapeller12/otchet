# Матрица дочернего общества: рабочая фиксация

Статус: `WORKING_REFERENCE`, не утверждённый эталон.

## Обязательная структура

По разделам 4.2 и 5.3 `AGENTS.md` сохраняются:

- иерархия `изготовитель/поставщик → изделие/ДСЕ/ПКИ`;
- договорной или годовой объём;
- утверждённый план;
- недели или даты периода по горизонтали;
- поставка накопительно;
- отклонение и профицит/дефицит.

Точные адреса, формулы, комментарии и иные метаданные рабочего источника не публикуются.
Импорт нельзя строить без утверждённой координатной карты, устойчивых бизнес-ключей и
владельцев показателей.

## `OPEN`

- реальный перечень организаций и подчинённость;
- коды изделий, ДСЕ и ПКИ;
- единица горизонтального периода для каждого блока: дата или неделя;
- источник договорного/годового объёма и утверждённого плана;
- карта вводимых, импортируемых и расчётных ячеек;
- точные правила накопления, отклонения и закрытия периода.
