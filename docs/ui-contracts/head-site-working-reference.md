# Матрица головной площадки: рабочая фиксация

Статус: `WORKING_REFERENCE`, не утверждённый эталон.

## Обязательная структура

По разделам 4.2 и 5.2 `AGENTS.md` сохраняются:

- группы `изготовитель/поставщик → сборочный комплект` и
  `изготовитель/поставщик → готовое изделие`;
- план выпуска перед фактом выпуска;
- разбивка по кодам и модификациям;
- даты месяца по горизонтали;
- блок `всего получено`, `всего использовано`, `остаток изделий`;
- месячные и накопительные итоги.

Точные адреса, формулы, комментарии и иные метаданные рабочего источника не публикуются.
После утверждения обезличенная версия должна получить отдельную координатную карту для
импорта и визуальной регрессии.
