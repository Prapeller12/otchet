# Матрица головной площадки: контракт формы

Актуализация: 19.09.2026. Основание: приложенный владельцем образец и прямое
указание строго сверить рабочие поля. Обезличенная карта сверки приведена в
[reference-audit-dev23.md](reference-audit-dev23.md); вычисления — в
[ADR-0015](../decisions/ADR-0015-head-monthly-report.md).

## Обязательная структура

- Шапка: год/период, шифр изделия, завод, изображение готового изделия и дата
  состояния; итоги и месячные планы/факты готовых изделий по кодам/модификациям.
- Составные части по вертикали: номер, обозначение, наименование, входимость,
  изображение и производители. Одна часть может иметь несколько производителей.
- Месяцы по горизонтали; внутри каждого месяца «План» перед «Фактом».
- Начальный остаток, расход, склад и дефицит/профицит общие по составной части.
  Производственный факт и договорное обязательство — разные показатели.
- Месячные и накопительные итоги явно подписаны и не смешивают периоды.

## Сохранённые решения владельца

Расход = фактический выпуск готовых изделий × входимость. Склад = начальный
остаток + факт производителей − расход. Дефицит/профицит = начальный остаток +
факт производителей − план производителей. Планы частей уже выражены в штуках
частей. Исходная формула с повторным включением факта не воспроизводится.

Месячный факт связанных дочерних обществ проверяет факт головной площадки,
но не подменяет его. Настройка связей и запрет повторного назначения сохраняются.
Пустые исходные данные не превращаются в ноль.

## Оставшиеся решения по данным

Реальные названия, коды и их соответствие другим отчётам задаёт владелец;
скрытые подписи образцов не угадываются. При переходе от суммарного выпуска к
разбивке по кодам существующие значения сохраняются и проверяются на
согласованность. Автоматического распределения месячных значений по дням нет.

Этот контракт фиксирует требуемую структуру; реализацию каждого исправления и
ограничения проверяет протокол выпуска. Исходные книги и частные метаданные
не публикуются в репозитории.
