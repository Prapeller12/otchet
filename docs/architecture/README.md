# Архитектура

Обязательная граница слоёв:

```text
frontend
  -> типизированный application-контракт
application / use cases
  -> domain
  -> repositories
  -> SQLite или PostgreSQL
```

Бизнес-формулы реализуются один раз в domain/application и используются локальным IPC, REST API и экспортом. React не обращается к SQLite и не является источником итоговых расчётов.

Подробная архитектура будет зафиксирована после завершения контрактов этапа 0. Изменение утверждённого технологического стека требует отдельного ADR.
