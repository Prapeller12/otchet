# Альфа-проверка оформления 0.1.0-dev.6

Область: только визуальное оформление по запросу владельца программы.
Основа — версия dev.5. Backend, bridge/API, расчёты, миграции, схемы и бизнес-правила
в этом изменении не редактировались. Номера версий и описание релиза обновлены для
отдельного тестового ZIP, сценарий сборки сохранён.

## Образец

Frontend [Prapeller12/kanban-python-code-](https://github.com/Prapeller12/kanban-python-code-/tree/9ac4f399b5128a8dc4d1b01faabfbb6477c07963/frontend/src),
снимок `9ac4f399b5128a8dc4d1b01faabfbb6477c07963`.
Изучены исходники стилей и компонентов; приложение-образец не запускалось.

| Источник в frontend/src образца | Применение в отчётности |
| --- | --- |
| styles/design-tokens.css, styles/pk-components.css | Зелёная палитра, нейтральные поверхности, состояния, радиусы, системные шрифты |
| blocks/header/header.css, blocks/page/page.css | Компактная тёмная шапка, светлый фон, плотность рабочего пространства |

Это перенос визуального языка на существующую матрицу отчётности. Канбан-доски
и бизнес-компоненты образца не переносились. Активная вкладка использует основной
зелёный токен вместо прежнего красного подчёркивания из tabs.css образца.
SVG-значки локальные и декоративные; сетевые шрифты и зависимости не добавлялись.

## Проверки

- Сравнение TypeScript AST до и после изменения: 7 обработчиков App и 21 обработчик
  ReportMatrix совпадают; операторы логики компонентов до JSX-return совпадают.
- Существующие 19 DOM-тестов интерфейса: матричный ввод, предпросмотр, Excel,
  настройки, размеры столбцов, сворачивание месяцев и переименование.
- TypeScript обоих проектов, production build, автономность ресурсов frontend,
  JSON/TypeScript-контракты и обязательные проверки репозитория.
- Backend проверяется прежним набором из 225 тестов; исходники не изменены.

Результат Windows-сборки и self-test упакованного EXE проверяется отдельно в Actions
для опубликованного коммита. Self-test не открывает пользовательское окно и системные
диалоги выбора файлов. Chromium для локальных скриншотов не удалось загрузить из-за
сетевого тайм-аута; визуальная проверка настоящего окна остаётся ручной. DOM-тесты
не подтверждают качество отрисовки при разных DPI.

## Ручной тест

В ZIP добавлены сценарии оформления в TESTING.txt, включая обычное/развёрнутое окно,
масштаб Windows 125–150%, закреплённые столбцы, календарь, настройки, клавиатуру
и Excel-предпросмотр. Прежние функциональные сценарии сохранены.

Распаковать в отдельную папку, запустить start.cmd. Для проверки прежних данных
использовать копию data/reporting.sqlite3 из закрытой программы, сохранив старую
папку целиком. Системный WebView2 и функциональные ограничения
[dev.5](alpha-dev5.md) сохраняются.
