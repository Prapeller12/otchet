# Проверка dev.16
Excel сохраняет полный год и карту обратного импорта, но скрывает свёрнутые в программе месяцы и открывается на первом видимом. Если свёрнуты все месяцы, экспорт показывает полный год. Общие поля детали объединены по производителям. Выбранная неделя остатка передаётся в экспорт. Существующие значения и скрытые периоды не удаляются.

Проверка: показать сентябрь, экспортировать. Сентябрь виден при открытии; числовые итоги совпадают с рабочей формой. Раскрыть январь в Excel — данные сохранены. Изменить поступление в копии и импортировать — карта редактируемых ячеек сохраняется.

Во всех отчётах новые позиции, производители и показатели создаются с пустыми названиями. Подсказки не являются значениями. Обязательные названия проверяются перед сохранением. Ранее сохранённые названия не стираются.
