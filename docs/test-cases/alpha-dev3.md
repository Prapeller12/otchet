# Альфа-проверка 0.1.0-dev.4 (настраиваемые поля dev.3)

Дата: 06.09.2026. Область: настраиваемые рабочие поля, изображения, формулы и Excel-обмен.
Тестовые данные синтетические; исходные числа сверены с листом «Учёт ДСЕ и ПКИ»
книги «ежедневный отчёт.xlsx». Пользовательские БД и исходные книги не изменялись.

Сценарии нового редактора находятся в `test_workspace_fields.py`,
`test_worksheet_formulas.py` и `position-fields.test.tsx`:
категории, изображение, переименование, копирование структуры позиции,
добавление/перестановка/скрытие показателей, повторное чтение после перезапуска,
проверка неизвестных ссылок и циклов, деление на ноль, сохранение Decimal,
атомарный отказ при неверных настройках, защита другой организации,
невозможность ручной записи в рассчитанное поле, пересчёт после Excel-импорта.

Контроль исходной книги: нормы B1:M1, остатки B4:M5.
Первый день: `min(floor(остаток / норма)) = 23`; второй день — `30`.
Интеграционный тест воспроизводит все 12 позиций. Переход между снимками в тесте
смоделирован отдельными поступлениями/использованиями; это тестовая реконструкция,
а не восстановленный журнал реальных операций.

Исправлены найденные дефекты: отказ при смене типа сохранённой строки,
положение нижнего расчётного блока при добавлении многих позиций,
запись устаревшего пакета импорта в показатель, ставший расчётным.
В dev.4 дополнительно ограничены экстремальные десятичные порядки, чтобы формула
не создавала строку результата с миллионами нулей; числовой ноль нормализуется.

## Границы проверки

Локальные тесты выполнены на Linux. DOM-тесты не подтверждают визуальный вид настоящего
окна WebView2, native file dialogs или поведение Windows. Загрузка Chromium для
дополнительного браузерного прогона была недоступна (HTTP 502 и тайм-ауты).

Windows workflow собирает EXE и выполняет `--self-test`: миграции, изображение через Pillow,
сохранение конфигурации, вычисление 23/30 и export → preview → commit трёх форм.
Результат конкретного запуска проверяется в GitHub Actions после публикации кода.
Этот self-test не открывает окно и не заменяет ручную приёмку Windows.

Формулы ограничены арифметикой, сравнениями, SUM/MIN/MAX/IF/ROUNDDOWN/CUM;
ссылки используют стабильные коды одной позиции, NORM и OPENING.
Настройки применяются к рабочей форме, не изменяют утверждённую BOM.
Комплектность — минимум по явно включённым показателям READY_SETS всей формы.
При нехватке исходных данных возвращается пустое значение, при ошибке — сообщение.
Выгрузка содержит снимки рассчитанных значений и примечания с формулами;
фотографии хранятся в программе и backup SQLite, не переносятся через Excel.

## Ручной тест

Распакуйте новую тестовую сборку в отдельную папку, запустите `start.cmd` и выполните
сценарий из `TESTING.txt`. Для проверки переноса старых данных используйте копию
`data/reporting.sqlite3` при закрытом приложении; оригинальную папку сохраняйте.
Проверьте три вкладки, две организации, фотографию, формулу, сохранение/перезапуск,
выгрузку/загрузку Excel и длинные наименования при вашем разрешении экрана.
Сборка использует системный WebView2; тест на чистой Windows без него не подтверждён.
