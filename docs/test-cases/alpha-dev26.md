# dev.26 — простой ввод, отдельная настройка и защищённая база

Основание: последнее указание владельца и ADR-0017. Три роли являются правами
доступа, а не обязательной последовательностью трёх подписей.

## Что изменено

- Раздел «Администратор»: сведения об изделии, план, организации, строки формы,
  ответственные лица. В базе может быть только один администратор.
- В основном поле две кнопки: «Сохранить» и «Ещё». План и сведения об изделии
  доступны для чтения; фактические значения вводятся в прежнюю матрицу.
- Три шага подсказок при первом открытии, повторный просмотр через «Как заполнить».
- Каждая запись требует свежего кода проверяющего или администратора; настройка
  и импорт произвольного Excel требуют кода администратора. Отказ сохраняет черновик.
- База и новые резервные копии зашифрованы SQLCipher. При запуске базу открывает
  проверяющий или администратор, затем сотрудник заполняет форму. Руководителю
  проекта ключ расшифрования базы не выдаётся.
- Старые подписи и криптографические профили сохраняются. Прежних проверяющих
  можно подключить к открытию новой базы через «Разрешить вход» с двумя кодами:
  кодом администратора и собственным кодом проверяющего.

## Приёмка

Проверяются прямые вызовы native API без разрешения, неверный код, код руководителя
проекта, повторная запись без нового подтверждения, запрет изменения плана
проверяющим, единственность администратора на уровне БД, сохранение точных чисел,
работа выпуска по кодам, отказ и повтор сохранения без потери черновика.

Защищённое хранение проверяется настоящим SQLCipher: чтение обычным SQLite
невозможно, неверный ключ и повреждённый шифротекст отвергаются, резервные копии
сохраняют шифрование. Прерванная первоначальная настройка и перенос старой базы
продолжаются с прежним кодом. Отсутствующая настроенная база не создаётся заново.

Windows CI собирает portable ZIP, запускает packaged self-test и настоящее окно:
вход, подсказки, две основные кнопки, неверный код/правильное сохранение, подпись,
компактная шапка, настройки администратора. Скриншоты сохраняются артефактом CI.
Успешность конкретного запуска определяется его результатом, а не этим документом.

## Первый запуск и перенос

Распакуйте весь ZIP в новую папку и запустите `start.cmd`. Создайте администратора,
запишите его код отдельно от компьютера. Затем откройте «Администратор», настройте
план/формы и добавьте проверяющих. Программа работает без установки Python/Node.

Для переноса закройте обе версии и сохраните полную резервную копию исходной папки.
Скопируйте рабочую папку `data` в новую распакованную программу. Старую незашифрованную
базу преобразует первый вход с действующим кодом администратора. Сохраняйте базу
вместе с соседним файлом `*.keys.json`; не смешивайте файлы разных копий.
Руководство пользователя находится в `docs/user-guide.md`.

Код администратора восстановить по имени нельзя. Потеря всех кодов означает
потерю доступа. Старые внешние копии SQLite и экспортированные Excel/PDF сами
по себе не шифруются. Защита не предотвращает удаление/полную замену файлов ОС,
изменение работающего процесса отладчиком или откат всей папки.
