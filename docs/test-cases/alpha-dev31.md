# dev.31 — уточнения после просмотра настоящего окна

Дополнение к [dev.30](alpha-dev30.md), без изменения формул, прав и печатных шрифтов.

## Основание

Полный Windows job dev.30 успешно прошёл: 450 backend tests, настоящий DPAPI,
распакованный EXE, защищённое сохранение и повторный процесс без входа.
При просмотре 21 PNG команда обнаружила две ошибки, не пойманные прежними assertions:

- Ежедневная подсказка называла позицию вместо исходных показателей «Получено» и
  «Использовано»: в настоящем контракте идентификатор столбца — wrk-daily-indicator, не indicator.
- Граница подсказки рассчитывалась по innerWidth, включающей полосу прокрутки.
  Поэтому правый край рамки мог частично перекрываться полосой.

## Исправление и проверки

Подсказки используют названия исходных показателей из реального контракта и
доступный размер documentElement.clientWidth/clientHeight. Добавлены регрессии
для пользовательских названий и полосы прокрутки. Native-проверка требует
явных названий источников и полного размещения подсказки в области содержимого.
Окно повторного запуска размещается целиком на рабочем столе для снимка.

Версия dev.31 проходит отдельные quality и Windows jobs. Успех dev.30 не считается
успехом dev.31: окончательные результаты фиксируются в PR и GitHub Actions.

Локально после исправлений: frontend **100 passed**, целевые native health tests
**24 passed**, TypeScript/build, Ruff/mypy, repository/offline checks и 6 хешей
печатного baseline проходят. Полный backend повторно выполняется в CI.
