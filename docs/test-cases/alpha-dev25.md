# dev.25 — компактная шапка головной площадки

Основание: прямое указание пользователя по скриншоту после dev.24.
Приоритет — последнее утверждённое требование владельца (AGENTS.md, раздел 2).

## Изменение рабочего поля

Только на вкладке «Головная площадка» большой блок «Изделие и изготовитель»
заменён одной строкой: годовой план → название изделия → шифр изделия.
Годовой план остаётся расчётным значением backend. Название и шифр редактируются;
компактные кнопки сохранения и отмены находятся в той же строке.

В этом блоке больше не показываются изготовитель, загрузка изображения,
годовой факт/процент/пояснения, редактор и добавление кодов выпуска.
Ранее сохранённые реквизиты и коды не удаляются и не перезаписываются при
сохранении названия/шифра. Месячная матрица, остальные вкладки, расчёты,
печать, экспорт и подтверждение отчёта не изменены.

## Проверка

- В шапке два текстовых ввода и один расчётный годовой план; подтверждённый ноль
  отображается как 0, отсутствие плана — как тире.
- Сохранение не отправляет пустой список кодов и сохраняет скрытые реквизиты.
- При ошибке остаётся черновик; отмена возвращает сохранённые поля.
- Проверка настоящего Windows-окна контролирует высоту блока и одну строку
  трёх полей, затем сохраняет скриншот.

Запуск: распакуйте весь ZIP в новую папку и откройте start.cmd.
