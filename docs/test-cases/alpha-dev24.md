# dev.24 — окончательная сборка ревизии

Включает все [изменения и ограничения ревизии dev.23](alpha-dev23.md).

Финальная независимая проверка нашла потерю точности чисел при выгрузке Excel.
Добавлен отказ от экспорта величин, которые формат Excel не может сохранить
без округления. Исходные данные остаются точными; пользователь получает
объяснение и может использовать PDF. Существующий файл не заменяется при ошибке.
Девять новых проверок включают большие целые, длинные дроби, отрицательные числа,
подтверждённый ноль и допустимые числа с 15 значащими цифрами.

До этой поправки прошли 332 backend-теста и 58 frontend-тестов. Дополнительно
после поправки прошли 9 проверок точности и 8 регрессионных проверок Excel.
Ruff, mypy, TypeScript, frontend build и offline policy прошли.

Windows ZIP публикуется только после packaged self-test и запуска настоящего
WebView2-окна из распакованного архива по пути с пробелами и кириллицей.
Проверка на чистых Windows 10/11 и утверждение складских привязок по кодам
остаются открытыми, как указано в протоколе dev.23.
