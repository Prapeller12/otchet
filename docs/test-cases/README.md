# Тестовые сценарии

Здесь хранятся проверяемые сценарии по domain, БД, API, frontend, Excel и portable-сборке. Контрольные бизнес-значения добавляются только со ссылкой на утверждённый источник.

Минимальный набор определён разделом 18 `AGENTS.md`. Реализованы:

- unit-тесты всех подтверждённых доменных формул, `Decimal`, пустого значения и нуля;
- контрольные значения готовых комплектов `23` и `30` из рабочей книги;
- все одинаково ограничивающие позиции;
- SQLite на пустой БД, внешние ключи, точные количества, границы BOM, атомарность,
  неизменяемость и сторно операций;
- JSON Schema contract-тесты валидных и невалидных матричных ячеек самописным автономным и
  стандартным Draft 2020-12 валидаторами.

API, импорт/экспорт, матричный UI, права, закрытие периода и portable Windows остаются
непроверенными, потому что соответствующая реализация или контракт ещё отсутствует.
