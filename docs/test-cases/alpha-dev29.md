# dev.29 — интерфейс по Frontend Reference Kit

Экранная тема перенесена из предоставленного `Frontend_Reference_Kit_v1(2).zip`:
светлые поверхности, красный акцент основного действия, локальный Golos Text,
единое оформление вкладок, полей, таблиц, окон входа и настроек. Карта источников,
экранов и обоснованных отклонений: [адаптация](../frontend-reference-adaptation.md).

Иконки сопровождают сохранение, печать, настройки, импорт/экспорт, добавление,
изменение и удаление. Стрелка «Ещё» показывает состояние раскрытия. Текст кнопок
сохранён; кнопки только с рисунком имеют доступные имена. Числовые ячейки и
выбор месяца не украшены дополнительными значками.

## Печать и данные

Генераторы PDF, три печатных TTF-шрифта и модуль подписи не изменяются относительно
dev.28; контрольные SHA-256 записаны в `config/frontend-reference/print-baseline.json`.
Экранная тема действует только в `@media screen`; прежний CSS печати сохранён
отдельно. Golos не подменяет печатные шрифты, их размеры или шаблоны.
Расчёты, база, роли, проверка личного кода, подписи и обмен Excel остаются прежними.
Новых миграций и зависимостей исполнения нет.

## Приёмка

Локально запускаются полный pytest и frontend-набор, TypeScript, Ruff, mypy,
контракт ячейки, проверка репозитория, JSON-схем профиля и автономности сборки.
Тесты иконок проверяют реальные действия во всех трёх отчётах, клавиатурное
раскрытие «Ещё» и доступные имена; это не сравнение текста CSS с самим собой.

Windows CI распаковывает готовый ZIP в путь с кириллицей и запускает настоящее
окно Fixed WebView2. Проверяются локальная загрузка Golos, основные цвета,
видимые SVG кнопок, сохранение и подпись своим кодом, PDF, импорт, закреплённая
навигация, один накопительный итог и контрольные числовые значения.
Снимки трёх отчётов и диалогов выполняются после загрузки шрифтов и отрисовки;
проверяемые размеры окна — 1440×900 и 1024×768. Это не подтверждает каждый
масштаб DPI или каждую версию Windows 10/11. Результат конкретного выпуска и
ссылки на снимки/CI фиксируются в PR после завершения сборки.

## Зафиксированные локальные результаты

20.09.2026: 428 backend-тестов и 87 frontend-тестов прошли; TypeScript, Ruff
(93 файла), mypy (89 файлов), контракт ячейки (5 корректных и 10 ошибочных
примеров), проверка репозитория, три JSON-профиля и production build проходят.
Автономная загрузка ресурсов проверена статически; шесть защищённых печатных
файлов имеют исходные хеши. Нативная Windows-проверка выполняется отдельным CI.

Первый Windows-прогон `35515932377` собрал и проверил ZIP, но остановился
на невозможности развернуть окно до 1440×900 при рабочем столе 1024×768.
Для повторного прогона CI предварительно задаёт и проверяет реальный экран
1920×1080 при 100% масштабе. Критерии проверки окна не ослаблены.

## Запуск

Распакуйте полный ZIP в новую локальную папку и откройте `start.cmd`.
Для обновления закройте программу и сохраните полную резервную копию `data`;
переносите базу вместе с её файлом `.keys.json`. Python, Node.js и Excel отдельно
устанавливать не требуется. [Инструкция с отдельным разделом для каждой вкладки](../user-guide.md).
