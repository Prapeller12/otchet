# dev.27 — работа ответственных, сохранение и печать

Основание: пять требований владельца по шести снимкам экрана, ADR-0018.

## Изменения относительно показанной формы

| Требование | Изменение |
|---|---|
| Ответственные редактируют поля | «План и сведения» доступен руководителю проекта и проверяющему; сохранение плана, реквизитов и значений подтверждается их собственным кодом. |
| Создание пользователя без повторного кода | Действующий сеанс администратора разрешает создание ответственного. Выход завершает сеанс. Прямой вызов без сеанса запрещён. |
| Закрепить переходы | Вкладки трёх отчётов и выбор организации остаются сверху при прокрутке. |
| Один накопительный итог | В ежедневной матрице видны дни выбранного месяца и «Накопительный итог» до конца этого месяца. Прежние месяцы не занимают отдельные столбцы. |
| Печать рядом с сохранением | Во всех трёх формах «Сохранить», «Печать / PDF A4», «Ещё». Личный код запрашивается автоматически; отдельной кнопки подтверждения нет. |

Порядок строк, расчётные поля, точность количеств, исходные пустые значения и
подтверждённые нули сохраняются. Однострочная шапка обычного экрана содержит
годовой план, название изделия и шифр. Реквизиты и планы меняются отдельно.
Накопительный итог использует backend through_month; остатки не суммируются.

## Приёмка

- Прямые IPC: руководитель и проверяющий сохраняют значения/планы/реквизиты,
  но не управляют пользователями и организациями без разрешения администратора.
- Создание ответственного внутри сеанса проходит без повторного кода;
  после выхода повторный прямой вызов отвергается. Второго администратора нет.
- Неверный код/отмена перед сохранением не записывают данные и сохраняют черновик.
- Подпись после сохранения относится к новой версии и выбранному периоду.
  Если данные записались, но подписать их нельзя, UI сообщает оба факта явно.
- Печать требует код и актуальные сохранённые данные, создаёт PDF с подписью.
- Ежедневная форма: смена месяца, единственный накопительный столбец,
  точные дроби, пустое/ноль, последний остаток вместо суммы остатков.
- Настоящее Windows-окно: создание ответственного, его редактирование и
  сохранение, автоматическое подтверждение печати, закреплённые вкладки,
  компактная шапка, прежние сценарии импорта и расчёта.
- Обновление зашифрованной dev.26 базы применяет новую миграцию с резервной копией,
  не меняет старые криптографические профили и сохраняет историю аудита.

Результаты конкретного выпуска определяются тестами и CI, а не этим перечнем.
Windows CI не заменяет отдельную проверку на каждой пользовательской Windows 10/11.

## Запуск и обновление

Распакуйте ZIP в новую папку, запустите `start.cmd`. Для обновления закройте старую
программу, сохраните полную резервную копию её папки и перенесите `data` вместе с
файлом `*.keys.json`. Не заменяйте единственную рабочую копию без резервирования.
Программу открывает проверяющий или администратор; затем руководитель проекта
может редактировать и подтверждать отчёты собственным кодом.

Подробные действия по каждой вкладке: [руководство пользователя](../user-guide.md).
