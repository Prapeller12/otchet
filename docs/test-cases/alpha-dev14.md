# Проверка dev.14
Изменения: производители в настройках расположены вертикально; компактные кнопки удаления с подписями для клавиатуры и подсказками; единая типографика. Сужение числовых недель не сужает заголовки итогов менее 110 px, включая ранее сохранённые размеры.

План выпуска сохраняется при выходе из поля или Enter. Остаток по умолчанию показан на конец месяца; нажатие заголовка недели меняет дату остатка и соответствующего PDF/подтверждения. Выпадающий список недели удалён.

Расчёты предустановлены в backend. Пустое поступление любого действующего производителя блокирует итог: «Заполните» и подсказка указывают конкретного производителя. Пустое значение не подменяется нулём. Введите 0 при подтверждённом отсутствии поступлений.

Проверка: начальный остаток 234, поступление 55, расход 3 + 45 + 65, второй производитель без поступления. Итог требует заполнения поступления второго производителя. После ввода 0 остаток = 234 + 55 − 3 − 45 − 65 = 176. При плане выпуска 100 и входимости 5 отклонение = 234 + 55 − 100 × 5 = −211. После перезапуска значения сохраняются.
