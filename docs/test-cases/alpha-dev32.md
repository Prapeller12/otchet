# dev.32 — переключатель подсказок

Основание: запрос владельца от 26.09.2026; [ADR-0021](../decisions/ADR-0021-optional-field-hints.md).

Флажок «Подсказки при наведении» рядом с «Как заполнить» включает/отключает
пояснения полей всех трёх вкладок и исходного Excel. По умолчанию включён.
Выключение убирает открытую подсказку, hover/focus не открывают новые. Повторное
включение восстанавливает их. Черновики и клавиатурная навигация матрицы сохраняются.

Настройка в config/ui-preferences.json переживает повторный запуск EXE. Код не нужен:
это оформление, а не запись отчёта. Политика авторизации и бизнес-данные не меняются.
Нет миграций, изменений формул, PDF или печатных шрифтов. Ошибка сохранения отображается
и возвращает прежнее положение переключателя. Повреждённый файл даёт значение true.
Файл предпочтения и атомарные временные файлы исключены из чистой поставки.

## Приёмка

1. Переключить флажок при открытой подсказке. Она должна исчезнуть сразу.
2. Проверить hover и фокус на трёх вкладках; включить обратно.
3. Изменить ячейку, переключить флажок: черновик не теряется и не сохраняется сам.
4. Выключить, закрыть EXE, запустить новым процессом: флажок выключен, пояснений нет.
5. Включить снова: пояснения работают во всех формах.
6. Проверить расположение флажка и доступность клавиатурой при 1024×768/1440×900.
7. Проверить отказ записи предпочтения, строгую схему API, атомарность и pristine ZIP.

Полные результаты фиксируются в PR и отдельных quality/Windows jobs для commit dev.32.
Наличие теста не является подтверждением его выполнения; Windows native CI проверяет
конкретную ОС/масштаб и не является сертификацией всех Windows 10/11.
