# dev.28 — итоговая проверочная сборка интерфейса

Содержит все пять изменений [dev.27](alpha-dev27.md). После просмотра настоящих
снимков Windows расширен единственный столбец «Накопительный итог», чтобы его
название не переносилось посреди слова на небольшом экране. Проверка окна ждёт
окончания выхода из административного режима и возврата прокрутки перед снимком.

Роли, расчёты, подписи и схема базы не меняются относительно dev.27. Выпуск имеет
отдельный номер, чтобы опубликованная dev.27 оставалась воспроизводимой.

Инструкция: [отдельные разделы по всем вкладкам](../user-guide.md).
Запуск: распаковать весь ZIP в новую папку и открыть `start.cmd`.
Перед переносом `data` закрыть программу и сохранить полную резервную копию;
переносить базу вместе с её файлом `.keys.json`.
