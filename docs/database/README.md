# База данных

Начальная SQLite-схема находится в `backend/migrations/0001_initial_schema.sql`. Она покрывает
только подтверждённое ядро: организационную область, изделия, компоненты, версионируемый BOM
и отдельные проведённые операции.

Подтверждено: SQLite применяется для локального MVP, PostgreSQL — для централизованного
режима; количества не хранятся как `float`; проведённые операции нельзя удалить или
редактировать, исправление выполняется связанным сторно; изменения схемы выполняются только
последовательными миграциями.

Первичный журнал хранит `operation_at` как ISO 8601 timestamp с обязательным часовым поясом
(`Z` или `±HH:MM`) отдельно от `created_at`. Календарная `operation_date` в контракте
матричной ячейки является отчётной координатой и не заменяет время первичной операции.

Пока не реализованы таблицы пользователей, ролей, периодов, планов, договоров, staging-
импорта и бизнес-аудита: их поля и права зависят от открытых решений владельца программы.
