# Проверочная сборка 0.1.0-dev.33

- Защищённые команды записи создают согласованные резервные комплекты БД и файлов доступа до и после изменения. Отказ предварительной копии блокирует запись; отказ последующей копии сообщается отдельно от результата сохранения.
- Excel проходит единое распознавание, проверку структуры/значений и подтверждение пакета. Добавлены режимы создания, дополнения и обновления, серверные соответствия и формат собственного обмена v2 с чтением v1.
- Неизвестные границы недель уточняются для столбца целиком. Неоднозначности и неподдерживаемые формулы остаются явными ошибками; пустые ячейки по умолчанию не стирают рабочие значения.
- Исправлены контроль активного ввода исходной книги и предварительный пересчёт после ошибки сохранения. Добавлено управление сменой кода, отзывом доступа и передачей роли администратора.

Распакуйте полный ZIP в новую локальную папку, сохраните прежнюю рабочую папку и прочитайте `TESTING.txt`. EXE отдельно не переносится. В поставку включён WebView2 Fixed Runtime; устанавливать Excel, Python или Node.js не требуется.

Это alpha, а не подтверждение работы всех исходных книг и всех конфигураций Windows 10/11. Workflow выпуска содержит проверки реального окна и повторного запуска; его результаты относятся к использованной среде. Невведённые в БД черновики не восстанавливаются резервной копией БД. Полные дампы памяти не включены; старые копии автоматически не удаляются.

Инструкции: `docs/user-guide.md`, `docs/test-cases/alpha-dev33.md`, `docs/imports/matrix-exchange-v2.md`. Ограничения Windows 10: `docs/decisions/ADR-0001-webview2-fixed-runtime-windows10-acl.md`.
