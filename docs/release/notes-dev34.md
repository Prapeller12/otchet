# dev.34 — единый черновик и заготовки с сентября 2027

Ввод заголовка, плана, выпуска и ячеек сохраняется одним пакетом с проверкой ревизии.
При ошибке записи весь пакет откатывается. Потерянный ответ проверяется по постоянному
ключу операции; повтор не добавляет второй пакет. Состояния записи, подписи и копии
показываются отдельно. При переходе доступны сохранение, отмена изменений и возврат.

Поиск подсвечивает совпадения и не скрывает строки. PDF предварительно показывает
выбранный сохранённый период. Импорт сначала показывает проблемы и требует проверки
всего пакета. Настройки позволяют искать позицию и редактировать один объект.

«Администратор» → «Заготовки с сентября 2027» добавляет КГЭ и четыре дочерние площадки
одной транзакцией. Позиции: КГЭ 8, Молот 154, Кулакова 69, СРЗ 82, Равенство 62.
Наименования — технические подписи для самостоятельного заполнения; количества пусты.
Прежние отчёты сохраняются; повторное создание не перезаписывает новые данные.

База доработки: d3e549fa4f45d19db06d2feead880aa044ab245e, ветка dev33, не main.
Точный коммит новой сборки и CI run указаны в `release-manifest.json` внутри ZIP.
Имя prerelease содержит версию и SHA; существующие активы больше не заменяются.

Это тестовая сборка. Результат Windows CI относится к среде runner; он не заменяет
проверку сохранения, импорта, PDF и повторного открытия на целевых Windows 10/11,
а также проверку задач с представителями пользователей.
