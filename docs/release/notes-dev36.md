# dev36 — сетевой запуск и общие зашифрованные данные

База доработки: dev35, коммит 08b3ef9c87b4ee4217f61a89bb33076746b46037.
Сетевой режим запускается через ReportingSystemNetwork.exe из общей папки.
ReportingSystem.exe сохраняет прежний локальный режим.

Клиент, Python, Fixed WebView2, профиль браузера, SQLCipher и DPAPI-копия
ключа работают на локальном диске. Сервер хранит согласованные зашифрованные
поколения и CURRENT. Публикация выполняется под системной SMB-блокировкой
с проверкой общей ревизии. Неизвестный результат требует проверки операции;
старая версия не перезаписывает новые данные.

Проверка статуса сети не обновляет таблицу. Обновление явное; черновик при
конфликте сохраняется. Роли, личные коды, подписи, формы и исправления размеров
dev35 сохраняются. Настройки сервера: config/network.defaults.json;
адрес конкретной площадки задаётся в network.local.json рядом с сетевым EXE.

Архив создаётся до тестовых запусков и не содержит пользовательской базы,
личных кодов, ключей или настроек сервера. Предварительный выпуск публикуется
только после сборки и проверок обоих Windows CI jobs: Server 2022 и Server 2025.
Windows 10/11, физические удалённые компьютеры/сеть и целевой файловый сервер
требуют отдельной эксплуатационной приёмки; loopback SMB не заменяет её.
