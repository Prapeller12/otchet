# dev.35 — таблицы и диалоги в пределах рабочего окна

Рабочая область отчёта ограничена доступным размером окна. Панели над таблицей
и сама матрица прокручиваются внутри своих областей; строка состояния не перекрывает
ячейки. Широкая таблица прокручивается горизонтально без расширения страницы.
Диалоги ограничены размером окна, длинное содержимое доступно прокруткой.
На узком экране закрепляется только помещающаяся часть идентификационных колонок,
чтобы они не закрывали числовые поля. Ширины и порядок всех колонок сохраняются.
Начальный размер нативного окна и его минимальные размеры ограничены рабочей
областью Windows с учётом масштаба; панель задач исключена из доступного места.

Порядок строк и горизонтальные периоды, ввод пустого значения и подтверждённого нуля,
единый черновик, сохранение и пять заготовок с сентября 2027 сохраняются.

База: b1be84c12683b72dfd0f4b10d9195fcee6aaddf5, объединение PR №23
в ветку dev33. Это не текущий main. Коммит сборки и CI run указаны
в release-manifest.json внутри ZIP; prerelease содержит неизменяемый SHA.

Windows CI проверяет границы таблиц в реальном WebView2 при разных размерах окна,
включая 1366×768, 1280×720 и 1024×640. Указаны размеры нативного окна;
рабочая область меньше на рамку и заголовок Windows. Результат CI публикуется
только после завершения; наличие сценария не означает его прохождение.

Это тестовая сборка. Windows Server CI не заменяет проверку целевых Windows 10/11
при фактическом DPI рабочего места и приёмку с представителями пользователей.
