# Формат обмена матрицей v2

Версия 2 сохраняет форму листа «Отчёт», а также системную карту v1 с дополнительными
полями исходного состояния (`value_kind`, `quantity`). Чтение карт версии 1 сохранено.
Видимость колонок не влияет на полноту импорта: читаются все значения карты.

Лист `_Обмен v2` содержит JSON-снимок: UUID набора данных и организации, структуру
рабочих групп с изготовителями, шапку, первичные месячные планы и выпуск, производственные
коды, год отчёта и точные границы периодов. JSON разделён на фрагменты по 30 000 символов
из-за ограничения Excel. SHA-256 проверяет целостность снимка. Это не цифровая подпись.
Снимок содержит исходный перечень адресов и бизнес-координат, также покрытый SHA-256.
Полнота проверяется по этому перечню: дополнительные позиции целевой базы не обязаны
присутствовать в исходнике, но удалённая или подменённая запись системной карты блокирует импорт.
Связи из другой базы требуют явного сопоставления; совпадение локального ID не принимается
за доказательство идентичности. UUID базы и сущностей передаёт application-слой.

По умолчанию пустые значения имеют действие KEEP: они не очищают базу. Числовой ноль
имеет действие SET и переносится как подтверждённый ноль. Для явной очистки поля версии 2
используется `#CLEAR`. Количества с десятичной запятой и разделяющими пробелами читаются
как точные Decimal. Прочерк, дата, логическое значение и произвольный текст не становятся нулём.

В полях ввода поддерживается ограниченный автономный вычислитель: арифметика, скобки,
ссылки на этот же лист и SUM. Формула и статус проверки кеша сохраняются в происхождении
значения. Внешние и межлистовые ссылки, неподдерживаемые функции, деление на ноль и циклы
дают адресную ошибку. Кеш не подменяет проверенное вычисление.

Разрешено изменять значения ввода, шапку изделия и месячные планы/выпуск.
Структурные изменения возвращаются отдельными действиями предпросмотра и применяются
application-слоем с проверкой прав. Вычисляемые годовые итоги, проценты и остатки
пересчитываются; они перечислены как неимпортируемые поля. Выпуск по кодам и структура
сохраняются в снимке для переноса в другую базу.

Полная перестановка/вставка строк контролируется скрытым маркером строки; вставка и
перестановка колонок — заголовками. Дополнительно проверяются объединения ячеек.
Изменение структуры Excel блокирует использование старой карты до повторного экспорта.
Неизвестные листы, включая скрытые, выдают требование проверки вместо молчаливого пропуска.
В предпросмотре можно явно исключить лист с обязательной причиной. Включение неизвестного
листа требует отдельного импорта внешней книги: произвольные значения не получают
координаты автоматически. Решения и причины сохраняются в метаданных пакета.

## API адаптера

`read_exchange_snapshot(path)` возвращает снимок и массив `coordinates` вида
`{"source_cell":"BW7","coordinate":{...}}`. Это чтение без записи в базу.

Проверенное сопоставление другой базы передаётся адаптеру через:

- `matrix.exchange_source_dataset_id` — UUID исходной базы;
- `matrix.exchange_coordinate_remap` — словарь из канонического JSON исходной координаты
  в полную целевую координату; JSON использует sort_keys, ensure_ascii=False и разделители `,`/`:`.

Результат parse содержит `metadata.snapshot`, `metadata.structural_changes`,
`metadata.non_imported_fields`, число пропущенных пустых значений и происхождение
каждой ячейки. Сам адаптер не изменяет рабочую базу. Подтверждение пакета выполняется
одной транзакцией вместе со структурными действиями.
