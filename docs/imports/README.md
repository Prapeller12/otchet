# Импорт Excel

Рабочий Excel-контур включён для всех трёх матриц. Кнопка экспорта создаёт книгу с видимым
листом `Отчёт` и скрытой системной картой бизнес-координат. Пользователь изменяет только
разблокированные жёлтые ячейки. Импорт принимает книгу для той же формы и организации,
проверяет системную карту, значения и отсутствие формул в полях ввода.

Процесс: выбор `.xlsx`, ограничение размера 50 МБ, копирование в `imports/inbox`, SHA-256,
staging в SQLite, предпросмотр `NEW / CHANGED / SAME / ERROR`, подтверждение, backup и
сохранение в неизменяемые ревизии фактов. Повторный импорт уже проведённого файла
идемпотентен.

Готовые книги по приложенным образцам принимаются без системной карты. Сначала открывается
сопоставление исходных значений с действующими вводимыми ячейками выбранной рабочей формы.
Пользователь выбирает позицию, показатель и период; при необходимости исправляет число.
Несопоставленные, неподтверждённые, повторные целевые ячейки и неверные числа блокируют
перенос. Поля выделены, пояснение доступно при наведении. Для исключения нужна явная причина;
можно найти позицию фильтром и исключить несопоставленные поля в этом фильтре одной командой.

После проверки создаётся обычный import_batch. Подтверждение записывает report_fact_revisions
с проверкой ревизий и резервной копией. Исходная книга и решения сопоставления сохраняются
для аудита (reference_workbooks и неизменяемая reference_transfer_decisions). Повторный
проведённый источник не записывается заново. Отдельный просмотр книги не является переносом;
новый импорт нельзя провести напрямую без проверенного сопоставления.

Сопоставление пока ручное; автоматическое создание позиций и преобразование формул
источника в формулы рабочего поля не выполняются. Недостающие позиции и показатели
пользователь добавляет через «Настроить рабочее поле», затем повторяет импорт. Расчётные
поля программы не перезаписываются. Месячные итоги нельзя автоматически распределять по
неделям: пользователь должен предоставить соответствующие периоду значения либо явно
исключить такой итог. Строковые обозначения и порядковые номера не считаются количествами.

Ранее сохранённые отдельные книги остаются в списке по активной вкладке и организации.
Они не удаляются; для переноса можно повторно выбрать исходный файл кнопкой импорта.

Исходные материалы и их частные метаданные не помещаются в публичный Git-репозиторий.
