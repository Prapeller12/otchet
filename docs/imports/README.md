# Импорт Excel

Рабочие источники описаны в `docs/ui-contracts/`, но пока не утверждены и не имеют карты
вводимых/расчётных/импортируемых координат. Поэтому реализация парсинга остаётся
заблокированной: привязка к номерам ячеек сейчас была бы предположением.

Обязательный процесс: копирование во временную область, SHA-256, staging, валидация, предпросмотр `NEW / CHANGED / SAME / ERROR`, подтверждение, backup и проведение одной транзакцией.

Исходные материалы и их частные метаданные не помещаются в публичный Git-репозиторий.
