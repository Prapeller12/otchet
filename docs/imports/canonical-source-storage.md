# Исходная книга канонического импорта

Начиная с миграции `0018`, проверка канонического Excel сохраняет точные исходные
байты вместе с пакетом импорта в зашифрованной SQLCipher-базе. Таблица
`import_workbook_sources` содержит неизменяемый BLOB с исходной SHA-256 и размером
от 1 байта до 50 МиБ. `import_batch_sources` связывает каждый пакет с этой книгой.
Одинаковые байты хранятся один раз, даже если пользователи повторяют проверку
с другими решениями по листам. Контекстный `source_sha256` пакета по-прежнему
включает отчёт, организацию, период, режим и профиль; исходная SHA-256 остаётся
в `metadata.original_source_sha256`.

Порт `ExcelImportRepository` возвращает книгу только через
`get_workbook_source(batch_id)`. Байты отсутствуют в DTO предпросмотра, а
отображаемое имя файла сохраняется для происхождения данных. Репозиторий
записывает книгу, привязку, строки пакета и аудит проверки в одной транзакции.
Ошибка любой записи откатывает весь пакет.

`ExcelReportService.materialize_import_source` проверяет сохранённую SHA-256
до записи и создаёт файл исключительно в локальном `imports/inbox` клиента.
Имя формируется из проверенного UUID пакета и нового UUID ресурса; исходное имя
и прежний путь клиента не задают путь назначения. Создание использует режим
`xb`, контрольная сумма локальной копии проверяется повторно. Ресурс удаляется
при завершении контекста, включая ошибку проверки. Само первичное staging тоже
удаляет локальную копию после разбора. Сетевое поколение получает только
зашифрованную базу и разрешённые файлы доступа, без исходных `.xlsx`.

`validate_import` с `batch_id` использует этот ресурс, поэтому второй клиент
может повторить проверку пакета после загрузки поколения без папки первого
клиента. Отображаемое имя, исходная SHA-256, координаты, происхождение значений
и существующие правила идемпотентности остаются прежними. Сопоставление полей,
формы и проведение фактов выполняются существующим каноническим маршрутом.

Миграция не подбирает книги для старых пакетов. Если BLOB отсутствует, допустим
только прежний локальный файл с именем из 32 строчных шестнадцатеричных символов
и `.xlsx`, находящийся непосредственно в локальном inbox. Символьные ссылки
запрещены. Точное совпадение с сохранённой исходной SHA-256 позволяет один раз
архивировать книгу с аудитом `ARCHIVE_EXCEL_SOURCE`. Эту запись сетевой
координатор проводит как часть команды проверки.

| Код ошибки | Действие пользователя |
| --- | --- |
| `EXCEL_SOURCE_RESELECT_REQUIRED` | Исходная книга старого пакета отсутствует или прежнее имя нельзя использовать. Выбрать первоначальный Excel заново и повторить проверку. |
| `EXCEL_SOURCE_INTEGRITY_ERROR` | Байты, размер, контрольная сумма или локальный путь не прошли проверку. Повторная проверка остановлена; выбрать первоначальную книгу заново. |

Проверки находятся в `backend/tests/integration/test_import_sources_dev36.py`:
копирование зашифрованного снимка между клиентами с пустым inbox; сохранение
происхождения и идемпотентное проведение; откат при ошибке привязки; точное
восстановление старого источника; отсутствие подбора при недоступной книге;
проверки ссылок, путей, хеша, размеров, неизменяемости и коллизий локальных имён.
