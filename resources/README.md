# Ресурсы

- `templates/` — только утверждённые обезличенные шаблоны отчётов;
- `schemas/` — проверяемые схемы данных и импорта;
- `dictionaries/` — утверждённые справочники без пользовательских данных;
- `icons/` — локальные графические ресурсы приложения.

Для каждого Excel-шаблона обязательны карточка в `docs/ui-contracts/` и контрольная SHA-256.

В `schemas/report-cell/` находится текущий JSON Schema-контракт матричной ячейки. Рабочие
исходные книги не добавлены в `templates/`, пока владелец программы не утвердит их версии и
не будут подготовлены обезличенные копии.
