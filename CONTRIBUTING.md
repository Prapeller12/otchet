# Участие в разработке

## Перед началом

1. Полностью прочитайте `AGENTS.md` и релевантные документы из `docs/`.
2. Для командной разработки следуйте распределению ролей и контрольным точкам из
   `docs/development/agents-team.md`.
3. Убедитесь, что рабочая копия не содержит чужих незакоммиченных изменений.
4. Зафиксируйте критерии приёмки и затрагиваемые слои.
5. Если меняется утверждённый архитектурный принцип, сначала создайте ADR со статусом `PROPOSED`.

## Git-процесс

- Основная ветка: `main`.
- Изменения готовятся в отдельной короткоживущей ветке.
- Один pull request должен решать одну проверяемую задачу.
- Не включайте в коммит рабочие БД, пользовательские файлы, импорты, экспорты, backup, runtime и секреты.
- Не переписывайте опубликованную историю без прямого согласования.

## Проверка

Перед commit выполните:

```bash
python scripts/verify_repository.py
```

После появления прикладного кода список обязательных проверок расширяется тестами, линтерами и сборкой соответствующего модуля согласно `AGENTS.md`.
